# 07. Вертикальный срез v0.1 — CE-P00 «Пепел в помехах»

## Цель

Доказать подключение мода, одноразовый триггер, выбор системы, создание NPC, диалог, предмет, развилки, save/load, отложенное последствие и очистку.

## Состав

- один разведчик Агиллов;
- один placeholder-корпус;
- предмет «Обугленный регистратор»;
- сообщение ЦР;
- основной диалог;
- три основных и один провальный исход;
- три последствия;
- журнал;
- debug-меню.

Не входят вторжение, новые системы/правительства, четыре полноценные расы, уникальное оборудование и финальные арты.

## Состояния

| Код | Значение |
|---:|---|
| 0 | не запущено |
| 10 | ожидание условий |
| 20 | сообщение отправлено |
| 30 | система выбрана |
| 40 | разведчик создан |
| 50 | контакт |
| 60 | исход записан |
| 70 | ожидание последствия |
| 80 | завершено |
| 90 | провалено |
| 99 | очистка |

## Выбор системы

Система должна быть достижима, не уничтожена, не участвовать в обязательной битве и по возможности находиться возле чёрной дыры. При отсутствии идеальной точки помехи объясняются остаточным гиперследом.

## Поведение разведчика

- не атакует первым до контакта;
- держит дистанцию;
- при критическом уроне предлагает выбросить регистратор;
- может попытаться уйти;
- не преследует игрока бесконечно;
- при смерти создаёт не более одного предмета.

## Диалог

Разведчик:

> «Сигнатура не совпадает ни с одним наблюдаемым шаблоном. Вы свободный корабль. Поэтому прогноз невозможен».

Варианты:

1. «Назови себя».
2. «Выбрось данные и можешь уйти».
3. «Я не служу Совету. Давай поговорим».
4. «Мне всё равно, кто ты. Готовься к бою».
5. «Уходи. Сегодня я ничего не видел».

## Баланс исходов

### Убийство

`Evidence +20`, `AgillRep -25`, `InvasionAlert +15`, последствие `REVENGE`.

### Принуждение

`Evidence +15`, `AgillRep -10`, `InvasionAlert +8`, последствие `HACK`.

### Освобождение после разговора

`Evidence +5`, `AgillRep +20`, `InvasionAlert -3`, последствие `MESSAGE`.

### Уход без контакта

Доказательства 0, тревога +5, частичный провал.

## Последствия

- **REVENGE:** предупреждение о двух теневых сигнатурах; реальный отряд можно отложить до v0.2.
- **HACK:** часть навигационного журнала просмотрена; приходит ложная координата.
- **MESSAGE:** «Проверьте, кто первым закрыл врата. Не кто нажал кнопку. Кто первым перестал отвечать».

## Acceptance criteria

1. Событие не запускается дважды.
2. Разведчик и предмет существуют в одном экземпляре.
3. Save/load не дублирует объекты.
4. Все временные объекты очищаются.
5. Смерть цели до диалога не ломает миссию.
6. Уход цели не оставляет цепочку навсегда активной.
7. Смерть игрока не повреждает состояние.
8. Все строки локализованы.
9. В логах нет ошибок `CE_`.
10. Debug-сброс не затрагивает другие модули.

Срез готов только после скриншотов/видео четырёх исходов и матрицы save/load.
