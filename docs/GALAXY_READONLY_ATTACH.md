# Read-only attach scanner

## Назначение

`ce_galaxy_attach.exe` проверяет, можно ли после загрузки сохранения найти
текущий объект `Galaxy` без callback RScript. Инструмент открывает существующий
`Rangers.exe` только с `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`, перечисляет
читаемые committed-регионы через `VirtualQueryEx` и читает их через
`ReadProcessMemory`.

Инструмент не внедряет DLL, не создаёт удалённый поток, не меняет защиту страниц
и не записывает в процесс. В отчёте отсутствуют адреса и сырые байты: только число
кандидатов, четыре 64-байтных FNV-1a хеша и классификационные маски.

## Профили

Профиль по умолчанию требует только пересечение подтверждённых признаков ABI 4 и
ABI 5:

- zero-mask: `0818404000000400`;
- readable-pointer mask: `000300003000F801`.

Это широкий профиль. Код завершает работу успешно только при одном кандидате;
ноль или несколько кандидатов означают, что сигнатуру нужно уточнить.

Для конкретной сохранённой партии можно передать полные маски и `-Exact`.
Подтверждённые маски точки ABI 5 `CurTurn=301`:

- zero-mask: `0D58404000000400`;
- readable-pointer mask: `00070001F000F801`.

## Сборка и запуск

```powershell
powershell -ExecutionPolicy Bypass -File tools\build-readonly-attach.ps1
powershell -ExecutionPolicy Bypass -File tools\run-readonly-attach.ps1
```

Строгая проверка партии ABI 5:

```powershell
powershell -ExecutionPolicy Bypass -File tools\run-readonly-attach.ps1 `
  -ZeroMask 0D58404000000400 `
  -PointerMask 00070001F000F801 `
  -Exact
```

Коды завершения: `0` — ровно один кандидат; `4` — ноль или неоднозначное число
кандидатов; `2` — неверные аргументы; `3` — процесс нельзя безопасно прочитать.

## Результат на загруженном save

Самотест подтверждает полный путь `VirtualQueryEx` + `ReadProcessMemory` на
синтетической 256-байтной структуре. Затем scanner был запущен в новом процессе
игры после same-turn загрузки сохранения, для которого RScript latest остался
устаревшим:

- строгий ABI 5 профиль: ровно `1` кандидат;
- устойчивый профиль пересечения ABI 4/5: ровно `1` кандидат;
- оба профиля вернули одинаковые четыре хеша и полные классификационные маски;
- хеши: `[2893795901, 1103959046, 2882147232, 2462119518]`;
- zero-mask: `0D58404000000400`, pointer-mask: `00070001F000F801`;
- просмотрено около 670 MB committed readable памяти без записи в процесс;
- исходный `INSTALL.TXT` сохранил контрольный SHA256.

Это подтверждает, что текущий `Galaxy` можно повторно найти после load без
RScript callback. Единственный кандидат разрешает следующий read-only gate —
сравнение `after/reload`; он не подтверждает поля, конструктор, запись,
переключение карты или native save.
