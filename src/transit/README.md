# Interarm transit

Якорь — квестовый груз в трюме; ячейка расходуется; новый слот не используется.

Spike использует журналируемые фазы `PREPARED → DEBITED → SWITCHED → COMPLETE`.
При восстановлении резонансная ячейка списывается ровно один раз, а переключение
доводится до целевого рукава идемпотентно.
