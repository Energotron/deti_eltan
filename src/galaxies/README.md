# Galaxy contexts

CE-SPIKE-MAP начат с исполняемой офлайн-модели в
`tools/second_map_spike.py`. Она доказывает:

- отдельные seed и состояния `OLD_ARM` / `SECOND_HOME`;
- масштаб Второго Дома в пределах ±10%;
- обязательные сюжетные роли без дубликатов и без привязки к одной звезде;
- пакетную симуляцию неактивного рукава;
- три и более перехода в одном состоянии;
- восстановление незавершённой транзакции после save/crash.

Schema 3 также зеркалит число секторов старого рукава. Контрольный вход
`old_sector_count=19` детерминированно создаёт 19 уникально названных секторов
Второго Дома из пула 24 имён и обязательно использует все шесть территориальных
архетипов. Шесть архетипов не считаются шестью секторами.

Для контрольных 80 звёзд выбираются 80 уникальных видимых названий из пула 83.
Один и тот же seed повторяет карту, другой seed меняет набор и назначение 11
сюжетных ролей. Три первые роли всегда находятся в трёх стартовых открытых
секторах; остальные роли назначаются системам закрытых секторов и обнаруживаются
вместе с продвижением по карте.

Это контракт для будущего движкового адаптера, а не готовая нативная карта.
RScript API создания и переключения второго объекта Galaxy пока не найден.
